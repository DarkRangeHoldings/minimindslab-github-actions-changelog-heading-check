# Changelog Entry Check

Fails a workflow when a changelog text does not contain the required release heading.

Generated by MiniMindsLab 02.13 GitHub Action Factory.

## Usage

```yaml
- uses: ./path-to-action
  id: miniminds
  with:
    payload: '{"text":"# Changelog\n\n## 1.2.0\n- Added feature\n","version":"1.2.0"}'
- run: echo '${{ steps.miniminds.outputs.result }}'
```

Runtime: Node 24. No external dependencies. No network access.
